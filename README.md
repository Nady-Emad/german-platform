# Deutsch A1.1 – منصة التعلّم والامتحان 🇩🇪

منصة تفاعلية كاملة لتعلّم الألماني **A1.1 (Netzwerk neu)** من الصفر بالمصري، والاستعداد لامتحان الجامعة.
كل حاجة في المشروع ده **بدون إنترنت** و**بدون تثبيت أي برنامج**.

---

## 1) إزاي تفتح الموقع

1. افتح فولدر المشروع.
2. دوس دوبل كليك على **`index.html`**.
3. الموقع هيفتح في المتصفح (Chrome / Edge / Firefox).

> مفيش سيرفر ولا npm ولا إنترنت. كل حاجة ملفات ثابتة + JavaScript عادي.
> التقدّم بيتحفظ أوتوماتيك في المتصفح (localStorage) على نفس الجهاز.

---

## 4) خطة المذاكرة (المسار الست مراحل)

| المرحلة | تعمل إيه | المكان في الموقع |
|---|---|---|
| 1. **افهم** | اقرأ شرح كل فصل، خطوة بخطوة | 📘 شرح الفصول |
| 2. **احفظ** | كلمة + أداة + جمع. علّم ✓ كل كلمة حفظتها | 🗂️ القاموس + 🔤 تدريب الأدوات + 🃏 فلاش |
| 3. **اتمرّن** | تصريف الأفعال + ترتيب الجملة | ⚙️ الأفعال + 🧩 ترتيب الجملة |
| 4. **جاوب** | إجابات قصيرة + اختيار من متعدد | ✍️ + ✅ |
| 5. **امتحن** | امتحان بمؤقت بدون ما تبص على الإجابة | 📝 امتحان تجريبي |
| 6. **راجع** | الغلطات + البصمجة قبل الامتحان | 📊 تقدّمي + 🧠 البصمجة |

**نصيحة:** متعدّيش جزء قبل ما تحل تمارينه. الأخطاء اللي بتتكرر بتتسجل في «أسئلة محتاجة مراجعة».

## 5) حفظ التقدّم

- كل حاجة بتتحفظ **أوتوماتيك** في المتصفح (localStorage).
- الحالات المتاحة لكل كلمة: **لسه / بتراجعها 👁 / حفظتها ✓ / محتاجة تمرين !**
- تقدر تصدّر التقدّم كملف JSON من صفحة «تقدّمي».
- لو مسحت بيانات المتصفح، التقدّم بيتمسح — استخدم التصدير للنسخ الاحتياطي.

### ملاحظات أمانة علمية
- الأداة (der/die/das) والجمع لكل كلمة اتراجعوا على أساس **قواعد الجنس في ملف `Genusregeln.pdf`** + المفردات القياسية لـ Netzwerk neu A1.1.
- الأسئلة الأصلية منقولة من: `Fragen (K.1, K. 2).pdf` (4 صفحات) و`Wiederholung.pdf` (سلايدات المراجعة).
- التمارين المبنية على صور السلايدات (زي «Herr Müller» و«Sich vorstellen [3]») أُعيد بناؤها من السلايد بنفس المحتوى؛ لو حابب تطابق حرفي أكتر للفراغات النقطية، عدّلها في `js/data/questions.js`.
- مفيش ملفات صوت في الكورس، فالنطق بيستخدم **Web Speech API** بتاع المتصفح (صوت ألماني آلي).

## 7) لو حابب تعدّل أو تزوّد

- **كلمة جديدة:** ضيف سطر في `js/data/vocab.js` بالشكل:
  `["der","Tisch","ترابيزة","die Tische","Der Tisch ist groß.","الترابيزة كبيرة.","haus",3]`
  (الترتيب: الأداة، الكلمة، المعنى، الجمع، المثال، ترجمة المثال، التصنيف، الفصل)
- **سؤال MCQ جديد:** ضيف في `MCQ_GENERATED` جوه `js/data/questions.js`.
- **فعل جديد:** ضيف في `js/data/verbs.js` بالشكل:
  `["lernen","يتعلم","lerne|lernst|lernt|lernen|lernt|lernen","Ich lerne Deutsch.","أنا بتعلم ألماني.","reg",1,"hat gelernt","ملاحظة"]`
- **قاعدة جديدة:** ضيف عنصر في `window.GRAMMAR`.
- بعد أي تعديل: افتح الصفحة واعمل Refresh (Ctrl+F5).
